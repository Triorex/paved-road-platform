# Security policy

Please report vulnerabilities in the paved road privately through
**GitHub private vulnerability reporting** (Security tab → "Report a vulnerability").
Do not open a public issue. AppSec acknowledges reports within 2 business days.

Because every repository in the Triorex fleet runs these workflows, a weakness here is treated as
critical: fixes ship as a platform release and roll out through rings 0 → 1 → 2.
